ORGANIZING UNIT - PWA package

1. Upload ALL files and the icons folder to any HTTPS host:
   - Netlify: go to app.netlify.com/drop and drag this folder in.
   - GitHub Pages: upload to a repo, then Settings > Pages.
2. Open the link on a phone (Chrome on Android, Safari on iPhone).
   - Android: menu > Install app / Add to Home screen.
   - iPhone: Share > Add to Home Screen.
3. For an APK: go to pwabuilder.com, paste your link, choose Android.
